台灣地球物理觀測資料探索#

這是一個為研究生「打底」的教學網站，分成兩部。第一部帶你認識台灣四大類地球物理連續觀測資料（地下水位、地磁、地動、GNSS 地殼變形），學會從中央氣象署 GDMS（臺灣地震與地球物理資料管理系統）下載真實資料，並用 Python 做視覺化與探索，一起想清楚一個核心問題：

這些觀測量與地震之間有什麼關係？

第二部接著走進地震預報的世界：當「找前兆」這條路困難重重（第一部會誠實地讓你看到有多難），科學社群這三十年來實際走通的路是什麼？答案是統計地震預報模型——從描述餘震叢集的 ETAS、捕捉前兆尺度增加的 EEPAS，到把預報變成日常業務的作業化系統與機率式地震危害度分析（PSHA）。第二部以觀念為主，帶你把這一整套思想走一遍。

為什麼要觀測這些？#

大地震發生前，地殼處於應力累積的狀態。應力的變化「理論上」可能在多種物理量上留下痕跡：

觀測量

可能的地震關聯

對應章節

地下水位

應力改變孔隙壓力 → 水位異常升降；地震時的同震階變（co-seismic step）

3. 地下水位觀測

地磁

岩石應力改變磁化率（壓磁效應）、地殼流體移動產生電磁訊號

4. 地磁觀測

地動

地震活動度變化（b 值、前震序列）、波形本身

5. 地動觀測：波形與地震目錄

GNSS

板塊運動、震間閉鎖、同震位移、震後餘滑

6. GNSS 地殼變形觀測

要先講清楚：「地震前兆」到今天仍是沒有定論的開放問題，多數宣稱的前兆一經事後嚴格檢驗都站不住腳。所以這門課要練的，不只是把圖畫漂亮，而是先把資料處理的基本功打穩，再帶著健康的懷疑，去檢驗每一個看起來像「異常」的東西。

這個網站怎麼用#

第一部：地球物理觀測資料探索

  1. 1. 台灣地球物理觀測總覽：先看台灣有哪些測站、分布在哪裡。

  2. 2. 資料下載機制：GDMS 的註冊、下載機制，以及本站的 gdms_toolkit 自動化工具。

  3. 第 3 到 6 章：逐一認識四類資料，格式怎麼讀、怎麼畫、有哪些訊號藏在裡面。

  4. 7. 案例分析：2024/4/3 花蓮地震 M7.2：以 2024 年 4 月 3 日花蓮外海 M7.2 地震為案例，把四類資料放在同一時間軸上對照。這一章的結果可能會顛覆你的預期。

  5. 8. 怎麼嚴謹地問「這和地震有關嗎？」：怎麼嚴謹地問「這和地震有關嗎？」，一份前兆研究的方法地圖。

第二部：地震預報模型

  1. 9. 地震可以預測嗎？從預測走向機率預報：地震可以預測嗎？從決定論式的「預測」走向機率式的「預報」。

  2. 10. 地震目錄統計的進階課：目錄統計的進階課——Mc、b 值的不確定性、Omori 的皺褶、Båth、除叢的陷阱。

  3. 11. ETAS：把餘震邏輯寫成一條式子：ETAS——把「地震觸發地震」寫成一條條件強度函數，現代短期預報的主力引擎。

  4. 12. EEPAS 與 PPE：前兆尺度增加與中長期預報：EEPAS 與 PPE——前兆尺度增加現象與中長期預報。

  6. 14. 三個臭皮匠：混合與加乘模型：模型組合——混合與加乘，以及一場十年前瞻測試的教訓。

  7. 15. 預報好不好，怎麼算？CSEP 檢驗：預報好不好怎麼算——CSEP 的檢驗科學。

  8. 16. 從預報到危害度：PSHA：從預報到危害度——PSHA 與台灣地震模型。

  9. 17. 台灣：資料、模型與下一步：台灣——資料、模型與下一步。

第二部以觀念為主：每一章用文字與示意圖把模型的直覺講清楚，程式碼只是產生示意圖的工具（預設摺疊，有興趣才展開）。你不需要會寫這些模型，但讀完應該能看懂任何一篇地震預報論文在做什麼、以及該對它問哪些問題。

每一章都是可以下載執行的 Jupyter Notebook（頁面右上角下載按鈕）。所有圖表用的都是真實 GDMS 資料，重跑、改站、改時間範圍，只要改幾行程式。

環境準備#

git clone <本專案>
cd vizualization
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
pip install -e .            # 安裝 gdms_toolkit
cp .env.example .env        # 填入你的 GDMS 帳號

資料來源與引用#

本站所有觀測資料來自中央氣象署「臺灣地震與地球物理資料管理系統」（GDMS，https://gdms.cwa.gov.tw/）。使用資料發表研究成果時，請依 GDMS 網站規範引用資料來源（含 DOI：10.7914/SN/T5）。
